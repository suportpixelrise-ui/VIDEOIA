# fp-qa-export

Use para QA, stills ou exportação explícita. Entradas: episódio/configuração atuais, áudio real, registros e destino novo. Saídas: resultados técnicos distintos de revisão humana; MP4 apenas autorizado.

Leia automacao.md, pipeline.md e configuracao.md. Execute checks reais; para biblioteca use catálogo/stills. Sem áudio deixe QA de áudio pendente. Gate exige hashes/estágios atuais, assets, voz/legendas e revisão. Não fabrique aprovações, não sobrescreva renders nem faça recompressão ilimitada. Exportar não autoriza publicar, pagar, criar release ou merge.

Documentação: [manual do canal](../../../futuro-pratico/docs/futuro-pratico/README.md). Os demais documentos citados estão nesse diretório.
