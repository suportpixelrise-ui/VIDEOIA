# Base de produção FUTURO PRÁTICO

Infraestrutura adicionada ao projeto existente. Não é um episódio e não inclui nova narração ou exportação de vídeo.

1. [Identidade](identidade.md) e [bíblia visual](biblia-visual.md).
2. [Narrativa e repertório](narrativa.md).
3. [Biblioteca e propriedades](componentes.md).
4. [Pipeline retomável](pipeline.md) e [automação real](automacao.md).
5. [Configuração e presets](configuracao.md).
6. [Diagnóstico](diagnostico.md), [decisões](decisoes.md), [importação](importacao/README.md) e [QA](qa/RELATORIO.md).

No diretório `futuro-pratico`, use `npm run fp:doctor`, `npm run fp:assets:validate`, `npm run fp:test` e `npm run lint`. `npm run fp:preview` abre o Studio; selecione `FPCatalogoTecnico`. `npm run fp:stills -- out/fp-qa/NOVA-REVISAO` gera cinco PNGs, nunca MP4. Destinos existentes são recusados.

O repositório guarda código, documentação, Skills, catálogo e imagens canônicas. Staging, ZIPs e renders ficam ignorados. O acervo fornecido não veio acompanhado de cessão/licença independente; sua proveniência é documentada, mas direitos e continuidade exigem revisão editorial antes de publicação.
